# RouteNote v0.5.16

https://zuzitokisen.github.io/collection-note-demo/

報告、閲覧・編集、日月年集計、B5 PDF出力、設定の5画面です。報告・取引先等は架空データの試作で、実スプレッドシート接続・本人認証・端末間同期は未実装です。報告・設定は同じブラウザ内に保存します。税・端数計算と正式な請求額はまだ決まっていません。

## 社印

所有者の承認により、160×160pxの低解像度の実印影を標準画像として公開しています。画像選択なしで赤色の印影が請求書の会社名付近に入り、PDFにも反映されます。文字・罫線は印影の手前です。この公開画像は誰でも取得できます。高解像度の原本・参考写真・非公開の見本PDFは公開ソースに含みません。

「社印を変更」から高解像度の透過PNGを選ぶと、標準画像より優先します。初期状態では開いているページ内だけで保持し、「このブラウザに保存する」を選んだ場合だけ別のIndexedDB領域へ保存します。保存した画像は次回も優先されます。「標準に戻す」で保存を解除して標準画像に戻します。別の端末やブラウザへの同期はありません。共有端末では保存しないでください。これは認証付き・暗号化された会社用保管庫ではありません。PDF受取人は印影を複写・抽出できます。

選択画像はアプリから外部へ送信しません。PNGのみ、5MiB以下、各辺4096px以下、1600万画素以下。SVG・外部URL・全透明・不透明背景のみを拒否します。元画像は変更しません。選び直しでは旧保存を解除して未保存状態になります。保存済みPDFは変更しません。標準画像の読込が失敗した場合はPDF/印刷ボタンを止め、エラーを表示します。

更新は右上の「更新」から。ブラウザデータやアプリを削除しないでください。320・375・430px幅とブラウザ上のPDF作成を検証済み。iOS/Android実機の保存・印刷は未検証です。

## v0.5.13

名称をRouteNoteに統一。選択中の取引先タブを同色の入力ページへ接続。選択中を少し濃い青、非選択をさらに薄い青に変更。「入力中」の見出しを除き、下メニューを無彩色へ統一。PWAの識別ID、URL、ブラウザ保存キーは変更しません。既に追加済みのホーム画面名はOS側で自動更新されない場合があります。

## v0.5.14

報告の取引先タブ左端を入力ページ左端と揃え、タブ同士の隙間を詰めました。保存データ、入力中の値、選択時の青色、タブと入力ページの接続は維持します。

可燃・不燃は重量・設定単価・総計の横並びです。単価は選択した取引先の設定、未設定なら共通設定を初期表示し、その報告だけ直接変更できます。既存報告の編集では保存済み単価を基準にし、現在の設定を遡って適用しません。備考欄を1行にし、取引先選択と可燃の間の余白を詰めました。

その他は「総計」の金額入力、1行の備考の順です。閲覧・編集では重量の横に保存当時の単価を薄く表示し、現在の設定から引き直しません。

集計では保存単価を表示し、複数単価は内訳へ分けます。各記録の重量×保存単価とその他金額を一度ずつ合計し、総計と計算式を表示します。未使用の区分と、入力内容があるのに計算条件が欠ける区分は区別します。計算条件が欠ける場合は計算結果を表示せず、税・端数処理を推測しません。

## v0.5.15

集計は可燃・不燃・その他の横3列、保存単価は重量kgの横です。複数の単価が混ざる場合は「複数単価」と表示し、合計は各記録の保存値から計算します。総計は次段の全幅で、計算式と結果を一行に表示します。対象なしの金額は0円、必要な数量や単価が不明な金額は「—」です。過去記録・設定を変更せず、空欄を0へ書き換えません。内訳プルダウンと集計上部の説明欄を外しました。税額・正式な請求額の計算はまだ実装しておらず、PDFの該当金額は「—」です。

会社名の右の「詳細」を開くと、対象期間内の各記録を日付と金額列を揃えて表示します。内部の識別子と版は保持しますが、日常画面の開発用番号表示は除き、更新機能に必要な版情報だけを残します。

## v0.5.16

集計の総計欄と各回収日の詳細に、重量×保存単価＋重量×保存単価＋その他金額＝合計を表示します。日付・可燃・不燃・その他・合計の列を揃えます。複数単価は単価別の計算式を足し合わせ、合計重量にひとつの単価を掛けて代用しません。保存済み記録と空欄・0の区別は維持します。

## Googleログインの独立確認ページ

`auth-qa.html` はGoogleアカウントのログイン確認だけを行う独立ページです。PWA本体やスプレッドシートには接続していません。公開用Firebase設定のみを使い、サーバーの秘密鍵・実際の業務データを含みません。
