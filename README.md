# 回収ノート v0.5.10

架空データのPWAです。実際の会社・個人・銀行情報は入力しないでください。

https://zuzitokisen.github.io/collection-note-demo/

報告、閲覧・編集、日月年集計、B5 PDF出力、設定の5画面です。メンバー・取引先・処分物品は詳細を閲覧してから変更し、順番は長押しまたは上下ボタンで動かして保存します。その他に会社情報・銀行情報・税条件をまとめています。

初期単価は取引先の個別設定、なければ区分共通設定、両方空欄なら空欄です。0と未設定を区別し、過去の報告の単価は変えません。その他料金の月合計は特別清掃運搬料に一度だけ入れます。

税・端数計算と正式な請求額は未確定です。月間回収明細は最初から選択されていますが外せます。PDFはJIS B5縦182×257mmの画像PDFで、文字選択・検索はできません。

入力は同じブラウザ内だけに保存します。認証、Google Sheets接続、端末間同期、バックアップは未実装です。ブラウザデータ消去や別の公開先への移動で記録は引き継がれません。アプリを削除したりサイトデータを消したりせず、右上の更新を利用してください。新しい版がある時だけ更新内容のポップアップが出ます。キャンセルしても利用を続けられます。

設定のiから計算確認用サンプルを開けます。通常のデータとは別保存で、A1,100円・B350円の計算を確認できます。実シートには書き込みません。

スマホ幅でのブラウザ検証済み。実機iOS/Androidの長押し・キーボード・ホーム画面追加・オフライン・PDF保存と印刷は未検証です。
