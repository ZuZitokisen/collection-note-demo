# RouteNote v0.5.19

https://zuzitokisen.github.io/collection-note-demo/

報告、閲覧・編集、日月年集計、B5 PDF出力、設定の5画面です。v0.5.19では、閲覧・編集の「スプレッドシート」から、Google本人確認と登録メンバー照合を通して実データの閲覧・追加・訂正・削除・復元ができます。元の行を保持し、非公開の訂正履歴から実効日次データを作成して、スプレッドシート側の集計へ反映します。

「報告」「このブラウザ」の一覧・集計・PDF・設定は引き続き架空データによるブラウザ内の試作です。実データの一覧とは分離し、自動アップロード・コピー・統合はしません。ブラウザ内の試作集計やPDFが実シートを集計する機能ではありません。実データの単価・税・端数処理・正式な請求額は推測しません。

## 社印

所有者の承認により、160×160pxの低解像度の実印影を標準画像として公開しています。画像選択なしで赤色の印影が請求書の会社名付近に入り、PDFにも反映されます。文字・罫線は印影の手前です。この公開画像は誰でも取得できます。高解像度の原本・参考写真・非公開の見本PDFは公開ソースに含みません。

「社印を変更」から高解像度の透過PNGを選ぶと、標準画像より優先します。初期状態では開いているページ内だけで保持し、「このブラウザに保存する」を選んだ場合だけ別のIndexedDB領域へ保存します。保存した画像は次回も優先されます。「標準に戻す」で保存を解除して標準画像に戻します。別の端末やブラウザへの同期はありません。共有端末では保存しないでください。これは認証付き・暗号化された会社用保管庫ではありません。PDF受取人は印影を複写・抽出できます。

選択画像はアプリから外部へ送信しません。PNGのみ、5MiB以下、各辺4096px以下、1600万画素以下。SVG・外部URL・全透明・不透明背景のみを拒否します。元画像は変更しません。選び直しでは旧保存を解除して未保存状態になります。保存済みPDFは変更しません。標準画像の読込が失敗した場合はPDF/印刷ボタンを止め、エラーを表示します。

更新は右上の「更新」から。ブラウザデータやアプリを削除しないでください。320・375・430px幅とブラウザ上のPDF作成を検証済み。iOS/Android実機の保存・印刷は未検証です。

## 履歴：v0.5.18 認証付きシート閲覧

閲覧・編集の「スプレッドシート」で、既存の日次データ蓄積を読み取り表示します。「このブラウザ」の報告とは別のデータ源で、両者のマージ・コピー・自動同期はしません。Googleの最新IDトークンをHTTPSのリクエスト本文で送り、Apps Scriptが本人と非公開の登録名簿を照合します。公開コードには実データ・名簿・サーバー秘密鍵を含みません。

読み取り対象は日付、取引先、可燃kg、不燃kg、その他品名・料金です。保存当時の単価がないため、請求額・税・重量単価を推測しません。空欄と0を区別します。異常行やシートの構造変更は警告し、取得上限は原表10000行です。

取得データは一時表示に限り、アプリのlocalStorage・IndexedDB・Service Workerキャッシュに保存しません。ページ切替・ログアウト・認証変更で表示を消します。編集・削除・復旧・PDF出力はこのデータ源では提供しません。報告・設定の保存は従来どおりブラウザ内で、シートへの書込みは未接続です。

これはシート自体のGoogle共有設定を変更する機能ではありません。シート自身の共有先は所有者の設定に従います。実iPhone/Android端末、負荷・同時操作・業務用書込みの検証は未完了です。

## v0.5.19 認証付き実データの訂正

`スプレッドシート` タブは `reports.read` / `reports.change` を利用します。Googleの最新IDトークンと登録名簿を毎回サーバーで確認し、元の行を消さずに別の非公開訂正履歴へ追加・編集・論理削除・復元を保存します。ブラウザの試作報告や設定には触れず、自動アップロードしません。実データの単価・請求額・税額は推測しません。

変更は読込時のrevision/fingerprintを送信します。競合した内容は上書きせず、再読込を要求します。結果が不明な通信エラーでは新しい変更を停止し、明示操作による同一operationId・同一入力の確認／再送だけを許可します。再読込だけでは操作の受領確認にはなりません。未確認操作の不変な入力とGoogleのユーザー識別子を、送信前にlocalStorageへ保存して読み戻します。IDトークン・認証情報・取得一覧は保存しません。保存・読込・削除はアカウントごとの排他Web Lock内で行い、別タブの未確認操作を上書き・誤削除しません。ロックは認証や通信中には保持しません。Web Locks非対応・ロック取得失敗・保存不能・破損時は書き込みを停止します。再読込・タブ終了後も同じアカウントだけが操作を復旧でき、別アカウントへ入力を表示しません。ログアウトや画面移動では実データ表示・入力を消します。確定した拒否または保存確認後にのみ未確認操作を削除します。結果不明の既存操作は認証失敗でも残します。認証トークン取得は30秒で打ち切り、未送信の操作を保持します。自動再送はありません。共有端末では未確認の業務入力が端末に残ることに注意し、確認前にブラウザデータを削除しないでください。

元の行と非公開の訂正履歴から、削除済みを除いた実効日次データを作成し、既存のスプレッドシート集計へ接続しています。保存成功と実効日次データへの反映は別に表示します。競合時は変更を停止します。反映を確認できない場合は集計に使わない旨を表示します。これは正式な請求額の検証ではありません。シート自身の共有権限は変更しません。

未確認操作の保存は、このブラウザ・この端末のlocalStorageに限られます。別端末への復旧情報の同期、暗号化された保管、ブラウザの保存領域消去・端末紛失からの復旧は保証しません。アプリ画面では別アカウントに表示しませんが、端末の保存領域を直接閲覧できる人から業務入力を保護する仕組みではありません。結果未確認のときは、同じ端末・同じGoogleアカウントで「同じ操作を確認・再送」を使い、新規入力でやり直さないでください。

検証: Node 24.15以上の24系（またはjsdom 30対応のNode）で `npm install`、`npm run check`、`npm test`。自動テストは合成データ・モック通信だけで動作し、Googleや実シートへアクセスしません。DOMテストはjsdomを使用します。認証からPWA操作、保存、シート集計への反映までを通した公開環境のE2E、およびiPhone/Android実機での動作確認は未完了です。実シート側の集計接続確認と、PWA全体のE2E検証は別です。
