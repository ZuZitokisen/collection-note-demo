# 回収ノート v0.5.8

架空データのみのPWA試作です。実務データ・実個人情報を入力しないでください。報告と設定は、このブラウザだけに保存します。実スプレッドシート、本人認証、端末間同期、バックアップは未接続です。

- 最初に「利用者」を選びます。これはログイン認証ではありません。作成者と操作した人を履歴に残し、本番ではサーバーで検証したユーザーIDを使用する設計です。
- 報告、閲覧・編集、集計、出力、設定の5画面です。設定から取引先の詳細を開き、その下の「値段」で初期単価を設定します。当回だけの値段変更は過去の記録や設定単価を変えません。
- 数値入力中は「次の項目」「入力完了」を使えます。入力完了はキーボードを閉じる操作で、保存ではありません。
- メンバーと取引先は1行表示。上部の追加・選択から管理し、削除は過去名称と履歴を残す利用停止です。削除済みを含めると復元できます。
- メンバープロフィールは任意です。年齢は保存した時点の値で自動更新しません。免許欄は種類の記入を想定し、番号や証明書は扱いません。
- 出力は請求書様式の見本です。保存単価で求める記録料金を参考表示しますが、基本料、税、端数処理、採番、振込先が未確定のため、正式な請求には使用できません。元の表の計算不整合は引き継いでいません。

右上の「更新」から公開中の版と変更内容を確認します。更新があるとボタンが強調されます。入力を保存してから「新しい版を適用」を押してください。保存済みデータは消しません。アプリ削除やブラウザデータの消去は不要です。

公開先のドメインやブラウザが変わると保存領域も変わります。旧公開先の記録は自動では移りません。同じドメイン配下の別URLでは保存領域を共有する場合があります。

iOS/Android実機のホーム画面追加、ネイティブキーボード、オフライン利用とPDF出力は未検証です。初回読み込みとキャッシュ完了後は画面を再表示できる設計ですが、同期・送信待ち機能はありません。

区分・物品の事前割当は不要です。報告は可燃・不燃・その他の3区分、細かい内容は「備考」で補います。報告の備考は自由入力のみです。処分物品の登録情報は保持します。旧分類・設定・履歴は消去しません。更新内容は「閉じる」まで表示します。

画面のデモ版・試作ラベルを除き、保存と機能の説明にまとめました。入力の保存先や未接続機能は変更していません。

報告の取引先は横並びタブで切り替えます。表示中の取引先だけ編集し、保存時は全タブを確認して一括保存します。記録一覧の詳細ボタンから内容・作成者・編集者・履歴を確認できます。

処分物品は名前だけの一覧、上部の追加・選択・変更・複製・削除。削除履歴から復旧。i案内は同じ操作行。保存データと履歴は維持。


## B5 PDF出力

請求書は写真見本の5列・横罫線・下部の税率別内訳に合わせています。用紙は日本のB5（182×257mm）縦です。対象年月と発行日は別に指定します。月間回収明細は任意同梱または単独出力できます。その他料金（円）は重量へ加算しません。備考は別紙へ保持します。

「PDFをダウンロード」で生成・保存を試みます。保存が始まらない場合は、生成後に表示される「PDFを保存」を押してください。PDFは画像形式で文字選択・検索はできません。写真の実会社名・住所・銀行・印影は含めていません。正式な請求額は基本料・税・端数処理が未設定のため未確定です。

クラウドChromeで実際にPDFを保存してB5寸法と画像を確認しています。iPhone/Android実機、ネイティブ印刷は未検証です。実シート・認証・端末間同期は未接続のままです。

報告の取引先タブは「取引先1」「取引先2」…の連番で固定します。選択会社はタブ下の表示とプルダウンで確認できます。保存済みデータは変更しません。
