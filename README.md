# 回収ノート v0.5.3

架空データのみのPWA試作です。すべての報告と設定は、このブラウザの保存領域に記録します。実務データを入力しないでください。実スプレッドシート、アカウント認証、端末間同期、請求計算は未実装です。

設定 → 取引先 → 個別取引先 → 値段で初期値を設定し、報告では会社ごとの設定を表示します。その報告だけの値段変更もできます。

画面上部の「更新を確認」から更新します。保存済みデータは消しません。未保存の入力は更新前に保存してください。アプリ削除やブラウザデータの消去は不要です。

公開先のドメインやブラウザが変わると保存領域も変わります。旧公開先の記録は自動では移りません。同じドメイン配下の別URLでは保存領域を共有する場合があります。iOS/Android実機のホーム画面追加、オフライン利用は未検証です。
