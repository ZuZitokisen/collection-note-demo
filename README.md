## 社印

出力の「社印」から透過PNGを選ぶと、赤色で請求書の会社名付近に配置します。文字・罫線は印影の手前です。実際の印影・写真・見本PDFは公開ソースに含めていません。

初期状態では開いているページ内だけで保持し、「このブラウザに保存する」を選んだ場合だけ別のIndexedDB領域へ保存します。「外す」で保存も解除。別の端末やブラウザへの同期はありません。共有端末では保存しないでください。これは認証付き・暗号化された会社用保管庫ではありません。PDF受取人は印影を複写・抽出できます。

画像はアプリから外部へ送信しません。PNGのみ、5MiB以下、各辺4096px以下、1600万画素以下。SVG・外部URL・全透明・不透明背景のみを拒否します。元画像は変更しません。選び直しでは旧保存を解除して未保存状態になります。保存済みPDFは変更しません。

更新は右上の「更新」から。ブラウザデータやアプリを削除しないでください。自動テスト475件合格。スマホ幅とブラウザ上のPDF作成を検証済み。iOS/Android実機の保存・印刷は未検証です。
